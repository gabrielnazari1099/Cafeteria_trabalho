# Cafeteria_trabalho

Trabalho em grupo + Git + primeiro site real = muita coisa aprendida em pouco tempo.

Desenvolvemos o site The Coffee Stop, uma cafeteria fictícia com 5 páginas: Início, Cardápio, Sobre, Galeria e Contato.

Cada um ficou responsável por uma página em sua própria branch:
Erick Possamai Rodrigues Lemos - Início e Cardápio
Gabriel Nazari - Sobre
Leonardo Domingues - Galeria
Marcos Vinicius - Contato

No final, fizemos o merge de tudo na branch main.
